# QuickFix AI 🔧

An AI-powered home troubleshooting assistant.

## Features
- Diagnose household issues
- Step-by-step solutions
- Safety warnings

## Tech Stack
- FastAPI (Backend)
- HTML/CSS/JS (Frontend)

## How to Run

### Backend
cd backend
uvicorn main:app --reload

### Frontend
Open index.html in browser
